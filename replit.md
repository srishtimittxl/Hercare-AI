# HerCare AI

A women's health tracking mobile app with period tracking, mood logging, symptom tracking, a revamped Insights dashboard, and an AI health assistant powered by Groq (with support for OpenAI and Gemini).

## Run & Operate

- `PORT=5001 GROQ_API_KEY="gsk_..." pnpm --filter @workspace/api-server run dev` — run the API server (port 5001) with your Groq API key
- `pnpm --filter @workspace/hercare run dev` — run the Expo mobile app
- `pnpm run typecheck` — full typecheck across all packages
- Required env: `GROQ_API_KEY` — Groq API key (starts with `gsk_`) for the AI chat assistant (or `OPENAI_API_KEY`/`GEMINI_API_KEY`)

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- **Mobile:** Expo (React Native) with expo-router
- **Backend:** Express 5 (API server at Port 5001)
- **AI:** Groq Llama-3.3-70b-versatile via backend proxy streaming (compatible with OpenAI/Gemini)
- **Storage:** AsyncStorage for all user data (local, device-only)
- **Auth & Onboarding:** Name and Email ID captured upon first launch (stored locally)
- **Notifications:** Expo Notifications for daily hydration checks and cycle prediction alerts

## Architecture decisions

- All user data stored in AsyncStorage (device-local, no database sync required for MVP)
- OpenAI-compatible API responses generated by Groq (or Gemini) are mapped on the backend and streamed via SSE directly to the Expo client
- Streaming chat responses use `expo/fetch` which supports `getReader()` on all platforms
- Phase ring built with react-native-svg for crisp, animated cycle visualization
- Notifications toggles are managed inside the Profile tab and registered locally on the device

## Product

- **Home Dashboard:** Cycle phase ring, mood/symptom log cards, quick recommendations, navigation
- **Cycle Tracker:** Log period start/end with flow level; calculates cycle day, phase, average length, predicted next period
- **Mood Tracker:** Log one of 8 moods or add "+ Custom" moods; notes and history view
- **Symptom Tracker:** Log 7 symptoms or add "+ Custom" symptoms with 3 severity levels; history view
- **Insights Tab:** Revised screen featuring a flower indicator timeline, hormone percentage progress bars, wellness challenges with state persistence, and dynamic Ayurvedic tips corresponding to mood/symptom history
- **AI Chat:** Streaming chat assistant focused on women's health education with built-in medical disclaimers
- **Profile:** User profile stats, notification switch settings, privacy guidelines

## User preferences

- Stack: Expo (React Native) + Express + AsyncStorage (not Flutter/FastAPI as originally requested — functionally equivalent)
- Colors: Lavender (#9B6B9E) + Soft Pink (#E8689A) + White

## Gotchas

- `GROQ_API_KEY` is passed to the backend server at runtime — never hardcode it inside code files
- Never add `@workspace/api-client-react` to the Expo app's dependencies — it causes a duplicate React instance and "Invalid hook call" errors on web
- Restart the `artifacts/hercare: expo` workflow (not just Metro reload) after changing `package.json` or secrets
